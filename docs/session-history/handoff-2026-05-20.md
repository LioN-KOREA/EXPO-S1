## 메신저 기술 스택 (참고)
- **Realtime**: Supabase Realtime (WebSocket 기반, wss://). Postgres logical replication → publication `supabase_realtime` → WS broadcast → SDK `channel.on('postgres_changes')`
- **채널 키**: `thread:{thread_id}` (메시지 INSERT/UPDATE), `thread-row:{thread_id}` (last_read_at), `messenger-unread` (전역 뱃지)
- **cleanup**: thread 전환·언마운트 시 `supabase.removeChannel(ch)` 호출 — 메모리 누수 방지
- **fallback 없음**: WS 끊김 시 SDK 자동 재시도. polling/SSE 대안 미사용 (UX·비용 trade-off)
