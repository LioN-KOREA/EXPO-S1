### 5. 해결 — 마이그 039 + 클라 RPC 전환
**마이그 039** `interpreter_self_checkin(p_event_id uuid)` SECURITY DEFINER:
- 9 조건 검증 (인증, role, 행사 활성, 배정)
- INSERT 우선 (ON CONFLICT DO NOTHING) → race 안전
- skip 시 `FOR UPDATE` → status=NONE + INTERPRETER + REGULAR 만 WAITING 승격
- 상위 상태/RESERVE/SELLER 행 NO-OP (idempotent)
- `attendance_status_logs` 에 `change_method='QR'` 감사로그 자동
- 에러는 영문 키워드 + ERRCODE='42501'
- `SET search_path = public, pg_temp` (search_path injection 차단)
- REVOKE PUBLIC + GRANT EXECUTE authenticated

**클라 `QrScannerModal.tsx`**:
- `upsert(...)` → `supabase.rpc('interpreter_self_checkin', { p_event_id })`
- 에러 키워드 → i18n 매핑

**i18n `dictionaries.ts`**:
- `qrErrNotInterpreter`, `qrErrNotAssigned`, `qrErrEventInactive` ko/en

**마이그 038 정책 유지** (defense-in-depth).
