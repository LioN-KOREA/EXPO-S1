## 2. Codex 검수 반영

### Codex 1차 (#26 슬라이스)
- BLOCK 0
- **WARN 1 반영**: route.ts catch 의 `err instanceof Error` 가 PostgrestError 에 false. `extractErrorMeta(err)` 헬퍼로 `{message, code}` 추출 + SQLSTATE/도메인 키워드 양쪽 매핑.
- **WARN 2 반영**: invalid grade/rehire 값이 null clear 로 persisted. 비빈 값이 enum 미일치면 400 반환. 배열 body 도 거부.
- **SUGGEST 반영**: search input 이 back/forward 시 stale 표시. `useEffect([initialSearch])` 로 재동기화.

### Codex 2차 (045/046/047/stats)
- BLOCK 0
- **WARN 1 미반영 (후속)**: `src/lib/template/defaults.ts` 의 `SYSTEM_FIELD_KEYS` 가 여전히 2종 (`consultation_type`/`absence_reason`). 046 의 7 AI 키도 시스템 잠금 필요. **이유 (보류)**: `isSystemFieldKey` 가 label 잠금까지 적용 → PRD §24 "edit label of system fields" 와 충돌. 별도 후속 슬라이스에서 (1) label 잠금 분리 + (2) 7종 추가 동시 처리.
- **WARN 2 미반영 (후속)**: 047 trigger 가 `interpreter_id` 변경에만 발동. `profiles.role` 변경 시 cleanup 안 됨. **이유 (보류)**: role 변경 → cleanup = destructive. 운영 빈도 낮음. invariant 위반 시 admin 화면 영향 = 0 (`profiles.role='interpreter'` 필터로 자동 제외). 별도 PRD 로 정책 결정 후 처리.
- **SUGGEST 1 반영**: 047 FK `NOT VALID` → `VALIDATE CONSTRAINT` 패턴 적용. 운영 데이터 정합성 위험 회피.
- **SUGGEST 2 반영**: 046 의 label 보존이 JSON null/빈 문자열 케이스 통과 → `validate_report_template_fields` 위반 가능. `jsonb_typeof = 'string' AND length > 0` 가드 추가.
