# 수출상담회 엑셀 데이터 처리 스킬

## 목적
수출상담회 운영에 필요한 3종 엑셀 파일을 파싱하고, 상담일지를 엑셀로 내보냅니다.

## 기술 스택
- xlsx (SheetJS) - 엑셀 파싱 (브라우저/서버)
- ExcelJS - 엑셀 생성 및 스타일링 (서버)

## 처리 대상 엑셀 파일

### 1. 타임테이블 엑셀 (상담테이블.xlsx)
**구조:**
- Row 1: 헤더 (번호, 회사명, 바이어명, 인식, 날짜...)
- Row 2: 서브헤더 (타임슬롯: "10:00 - 10:40", "10:50 - 11:30" 등)
- Row 3+: 바이어별 데이터
  - Col 1: 번호
  - Col 2: 바이어 회사명 + 연락처 + 이메일 (줄바꿈으로 구분)
  - Col 3: 국가
  - Col 4: 부스번호
  - Col 5+: 각 타임슬롯의 셀러 정보 (회사명\n한국명\n담당자\n전화\n이메일 형태)

**파싱 로직:**
1. Row 2에서 타임슬롯 추출 (시간 범위 파싱)
2. Row 1에서 날짜 추출
3. Row 3+에서 바이어 정보 파싱 (줄바꿈 기반 분리)
4. 각 셀에서 셀러 정보 파싱 (줄바꿈 기반: 회사명EN, 회사명KR, 담당자, 전화, 이메일)

### 2. 상담일지 양식 엑셀
**구조:**
- Row 1: 필드명 헤더 (상담일자, 바이어회사명, 거래가능성 등)
- Row 2+: 예시 데이터 (타입 추론에 활용)

**파싱 로직:**
1. Row 1에서 필드 라벨 추출
2. Row 2+ 데이터에서 필드 타입 자동 추론
   - 숫자만 → number
   - 날짜 형식 → date
   - 특정 선택지 반복 → select (옵션 자동 수집)
   - 긴 텍스트 → textarea
   - 기본 → text
3. Admin이 프리뷰에서 타입 수정 가능

### 3. 통역사 계정 엑셀
**구조:**
- 이름, 이메일, 전화번호 등
- 임시 비밀번호 생성 또는 지정

## 내보내기 (엑셀 생성)
- 상담일지를 원래 양식대로 엑셀로 복원
- 스타일링: 헤더 색상, 테두리, 열 너비 자동 조절
- 시트별 분류: 날짜별 또는 통역사별
